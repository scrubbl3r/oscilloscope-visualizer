# **VIRTUAL SERVER SETUP**

**DO NOT DOUBLE-CLICK `index.html`. THE APP MUST RUN THROUGH THE SMALL LOCAL WEB SERVER DESCRIBED BELOW.**

## **FIRST-TIME WINDOWS SETUP**

**1. EXTRACT THE ENTIRE ZIP. DO NOT RUN THE APP FROM INSIDE THE ZIP.**

**2. OPEN THE EXTRACTED `oscilloscope-visualizer` FOLDER.**

**3. COPY THE CORRECTLY NAMED WAV FILES INTO THE `samples` FOLDER. READ `samples/README.md` FOR THE EXACT FILENAMES.**

**4. DOUBLE-CLICK `START-WINDOWS.bat`.**

**5. IF WINDOWS ASKS WHICH APPLICATION MAY OPEN THE FILE, SELECT WINDOWS COMMAND PROCESSOR.**

**6. YOUR BROWSER SHOULD OPEN `http://localhost:8128`. IF IT DOES NOT, OPEN CHROME AND ENTER THAT ADDRESS MANUALLY.**

**7. KEEP THE BLACK COMMAND WINDOW OPEN WHILE USING THE APP. CLOSING THAT WINDOW STOPS THE LOCAL SERVER.**

## **IF THE LAUNCHER SAYS PYTHON IS NOT INSTALLED**

**1. DOWNLOAD PYTHON 3 FOR WINDOWS FROM [PYTHON.ORG](https://www.python.org/downloads/windows/).**

**2. RUN THE INSTALLER. ON ITS FIRST SCREEN, CHECK `ADD PYTHON.EXE TO PATH`, THEN SELECT `INSTALL NOW`.**

**3. WHEN INSTALLATION FINISHES, CLOSE THE INSTALLER AND DOUBLE-CLICK `START-WINDOWS.bat` AGAIN.**

## **MANUAL WINDOWS START**

**OPEN THE PROJECT FOLDER, CLICK THE FOLDER ADDRESS BAR, TYPE `powershell`, AND PRESS ENTER.**

**IN THE POWERSHELL WINDOW, ENTER `py -m http.server 8128 --bind 127.0.0.1`.**

**IF `py` IS NOT RECOGNIZED, ENTER `python -m http.server 8128 --bind 127.0.0.1` INSTEAD.**

**OPEN CHROME TO `http://localhost:8128`. KEEP POWERSHELL OPEN. PRESS `CTRL+C` IN POWERSHELL TO STOP THE SERVER.**

## **MAC OR RASPBERRY PI / LINUX**

**OPEN TERMINAL IN THIS FOLDER AND RUN `./start-local.sh`.**

**IF THE SYSTEM BLOCKS THE SCRIPT, RUN `python3 -m http.server 8128 --bind 127.0.0.1` INSTEAD.**

**THEN OPEN CHROMIUM OR CHROME TO `http://localhost:8128`. KEEP TERMINAL OPEN. PRESS `CTRL+C` TO STOP THE SERVER.**

## **WHAT THIS SERVER DOES**

**THE SERVER ONLY MAKES THIS FOLDER AVAILABLE TO THE BROWSER ON THIS COMPUTER. IT DOES NOT UPLOAD THE AUDIO FILES OR PUBLISH THEM TO THE INTERNET.**

**THE ADDRESS `127.0.0.1` / `localhost` MEANS THIS COMPUTER. OTHER COMPUTERS CANNOT REACH THIS SERVER WITH THE PROVIDED COMMAND.**
